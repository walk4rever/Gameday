# Gameday 掼蛋 · 视觉设计方向初稿 · 统一设计 Spec

> 本文件是三个设计方向子代理的**唯一共同输入**。三者各自独立工作、只看本 spec、互不参考。
> 用户已确认的方向约束：**活泼、类似网易《蛋仔派对》/ 或酷酷的动漫风格**。

## 1. 产品是什么

**Gameday** —— 家庭联机卡牌游戏平台，手机浏览器打开即玩（PWA，免下载免登录免广告）。
首发游戏：**经典掼蛋**（4 人 2v2 对抗、两副牌共 108 张、每人 27 张手牌、级牌升级、逢人配万能牌、进贡还贡、炸弹体系）。
特色：人数不够由 AI 机器人补位；对新手有出牌合法性限制 + 实时教练提示；支持中途退出 AI 接管。
目标受众：**家庭成员**——家长与孩子、亲友聚会，2–4 人。孩子和无基础新手必须能独立打完一局。

## 2. 情感基调与气质关键词

活泼、Q 弹、糖果感、角色化、零压力、家庭同乐；另一条合法岔路：酷飒动漫（粗描边、速度线、霓虹、网点纸、漫画拟声词）。
**核心矛盾（每个方向都必须回答）**：掼蛋是信息密度极高的严肃卡牌游戏，包装可以萌/酷，但：
- 27 张手牌扇形叠排时，**左上角标（点数+花色）必须一眼可读**；
- 出牌/不要/提示按钮、剩余张数、当前级牌，永远不能被装饰淹没；
- 面向孩子与长辈：字号、对比度、按钮尺寸守可用性底线（正文 ≥14px、标签 ≥12px、对比度 ≥4.5:1）。

## 3. 输出格式（三个方向必须统一，否则无法横向对比）

- 交付物：**一个单文件 HTML「设计方向板」**，纯 HTML/CSS/SVG，零外部图片素材（允许 Google Fonts CDN）。
- 页面宽度 **1440px**，纵向滚动，按以下 6 个板块组织（每版内部布局骨架自定，但 6 个板块都必须出现）：
  1. **方向头版**：方向名 + 一句气质定位 + 色板条（5–7 色，标 hex）+ 字体组合说明；
  2. **牌面系统墙**：一排代表性牌面——黑桃A、红桃7（逢人配，带「配」徽章）、方块7（级牌，带「级」徽章）、梅花10、大王、小王 + 一张牌背。牌面是本设计的主角，做最大最精；
  3. **横屏牌桌主界面（hero 板块，占最大面积）**：见 §4；
  4. **竖屏牌桌**：同一局面的竖屏适配（卡片垂直流式排布，宽度约 390px 的竖长画布）；
  5. **欢迎页 + 房间大厅**：欢迎页=昵称输入+房号输入+「进入房间」大按钮+slogan；大厅=1号桌「经典掼蛋」可入座（4 席位：你 / 爸爸 / AI 补位×2）、2号桌「双升·开发中 🚧」、某桌「🚫 满员进行中」状态；
  6. **战绩结算榜**：头游/二游/三游/末游 排名卡 + 级数变化（我方升到 8）+「再来一局」大按钮。
- 截图：`playwright screenshot file:///绝对路径.html 输出.png --viewport-size=1440,900 --full-page`（本机全局 playwright 1.59 可用）。

## 4. 横屏牌桌必须出现的真实内容（画布比例约 844×390 逻辑像素，可等比放大呈现）

- **下方·自己**：27 张手牌扇形/弧形叠排（画出约 12–15 张示意即可，含级牌与逢人配徽章示例）；三大按钮「提示 / 不要 / 出牌」（出牌为主按钮）；教练提示条：「对子压不过顺子，试试提示」；昵称「你」+ 剩余 18 张。
- **上方·搭档**：徽章/头像位 + 昵称「爸爸」+ 剩余 7 张 + 刚打出的出牌墩（对 K）。
- **左右·两名对手**：徽章 + 昵称「AI·团团」「AI·圆圆」+ 剩余张数 12 / 3（剩 3 张要有「报牌」警示感）+ 各自出牌墩。
- **台面中央**：当前级牌指示「打 7」、我方 vs 对方级数（如 7 : 5）、上一轮最大出牌展示。
- **氛围**：回合指示（轮到你出牌的视觉强调）、炸弹/天王炸的特效暗示（可用一个「炸弹！」爆框元素示意）。

## 5. 真实内容数据（禁止 Lorem / 占位假数据）

- 花色与点数：♠ ♥ ♣ ♦ × 2–10/J/Q/K/A；大王、小王。
- 掼蛋专有视觉语义：**级牌**（当前打的点数，全局生效）徽标「级」；**逢人配**（当前级牌的红桃，万能牌）徽标「配」——这两个徽标是掼蛋 UI 的灵魂，必须做出辨识度。
- 文案用中文，「」引号。玩家名示例：你、爸爸、AI·团团、AI·圆圆。
- 房间号示例「8848」、昵称输入占位「给自己起个响亮的名字」。

## 6. 已知约束与禁忌

- 不涉及任何第三方真实品牌 logo / 产品图，无需外部图片素材；吉祥物/角色一律用 CSS 几何或 SVG 绘制，**不许画五官错位的人脸**（宁可做蛋形/团子/兽耳几何角色）。
- 避开 AI slop：SaaS 紫蓝渐变、GitHub-dark 深蓝底+霓虹、emoji 当功能图标（牌面花色与「配/级」徽章除外）、圆角卡片+左色条。
- 字体：中文 display 推荐站酷系免费字体（ZCOOL KuaiLe 站酷快乐体=活泼 / ZCOOL QingKe HuangYou 站酷庆科黄油体=酷飒粗黑），正文 Noto Sans SC / 系统圆体；西文 display 可选 Baloo 2 / Archivo / Nunito。Google Fonts CDN 直接引。
- 三版布局骨架必须互异：板块编排、导航/构图、牌桌构图至少一项结构性不同，不许共用骨架只换色。

## 7. 视觉母题提示（form 推导种子）

这个游戏独有的视觉素材：扑克花色四符号、级牌/逢人配双徽章、27 张扇形手牌的弧线、2v2 方位对坐关系、「头游→末游」的名次阶梯、蛋/团子形角色（呼应蛋仔语境）。每个方向交付时写一句「form 来自内容的哪里」。
