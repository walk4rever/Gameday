# Gameday (家庭联机游戏平台)

> **手机浏览器打开即玩，人数不足 AI 智能补位，专为家庭和聚会打造的轻量化联机棋牌平台。**

🌐 **在线体验**：[gd.air7fun.com](https://gd.air7fun.com)（备用域名：[gameday.air7fun.com](https://gameday.air7fun.com)）

---

## 🎯 项目愿景

在家庭聚会或亲子娱乐时，常常面临两个困扰：**“规则复杂，新手/孩子学不会”** 与 **“人数不够凑不齐一桌”**。

**Gameday** 致力于打造极致轻量、免安装、零门槛的网页端联机平台：
- **首发王牌**：**经典掼蛋 (Guandan)** —— 4人 2v2 升级对抗、逢人配万能牌、进贡机制。
- **储备游戏**：**双升 (拖拉机)** —— 研发中，支持定主打家、反主扣底抓分。
- **后续规划**：支持飞行棋、Uno、升级等经典家庭聚会桌游。

## ✨ 核心特性

- 📱 **移动端优先（Mobile-First）**
  - 原生支持手机竖屏与横屏一键无缝切换（支持界面旋转与防误触）。
  - 大按键点选、横滑理牌、触感震动（Haptics）与环境音效。
- 🤖 **智能 AI 补位与无缝托管**
  - 1 至 4 名真人均可秒级开局，空位由内置启发式 AI 自动补齐。
  - 玩家对局中断线或临时锁屏，AI 自动接管出牌，绝不卡死同桌其他玩家；重连后自动恢复控制权。
- 🚪 **直通牌桌极简流与方位体系**
  - 选房直通牌桌就地开局，消除冗余中间等候页；支持一键复制微信邀请。
  - 标准东南西北竞技方位体系，左上角融合双方打几与庄家级牌，右下角独立悬浮横竖屏切换。
  - 记牌器与计分板全局收敛至模态窗，牌桌视野开阔纯净。
- 🏡 **专属房间门户与名字模糊查找**
  - 告别机械房号，支持直接按房间名字搜索进入，提供常去家庭房间快捷入口与6位密码保护。
- 🏆 **长效战绩与家庭荣誉榜**
  - 支持场次积分结算、打过 A 决胜机制与掼蛋荣誉称号（雀圣、霸主等）。
- 🛡️ **严格 4 人局满员保护**
  - 每桌严格锁定 4 人。游戏开局后，第 5 位及后续访客无法插队，直观展示 `🚫 满员进行中` 警告。
- ⚖️ **服务端权威与手牌加密隔离**
  - 手牌信息服务端加密隔离，客户端仅接收自身手牌与他人剩余张数，从协议层杜绝客户端透视作弊。
  - 规则引擎本地与云端双重校验，兼顾零延迟交互与绝对公平。
- ⚡ **纯 Cloudflare 全球边缘架构**
  - **Cloudflare Workers**：全球 CDN 边缘节点极速响应。
  - **Durable Objects**：一个房间单实例常驻内存，原生 WebSocket 双向长连接，免除复杂集群同步。
  - **Workers Assets**：单页应用与服务端同域托管，无跨域开销。

## 🏗️ 架构与单仓结构

项目基于 `pnpm workspace` 组织，分为核心规则库、业务应用与服务端：

```
Gameday/
├── packages/
│   ├── rules/          掼蛋规则判定库（牌型分类、大小比较、合法出牌计算，纯 TS，零依赖）
│   ├── engine/         单局状态机（发牌、出牌循环、名次判定、纯 TS）
│   ├── bot/            启发式出牌 AI（跟牌、拆牌、逢人配智能判定）
│   └── protocol/       WebSocket 实时长连接消息类型与数据契约
├── apps/
│   ├── server/         Cloudflare Worker + Durable Objects 服务端应用
│   └── web/            React 19 + Vite 移动端 PWA 前端
├── pnpm-workspace.yaml
├── PRODUCT.md          核心产品设计与系统规格文档
├── TODO.md             开发路线图与待办任务跟踪
└── package.json
```

## 🚀 快速上手

### 环境依赖
- **Node.js** >= 22.0.0
- **pnpm** >= 10.0.0

### 安装依赖
```bash
pnpm install
```

### 运行自动化测试与类型检查
```bash
# 运行全量单元测试（77 项测试：规则、决策树、全自动对局仿真 100% 通过）
pnpm test

# 全项目静态类型检查
pnpm typecheck

# 生产环境打包构建
pnpm build
```

### 本地开发调试
```bash
# 终端 1：启动 Cloudflare Worker 本地仿真（包含 Durable Objects 实例）
pnpm --filter @guandan/server dev

# 终端 2：启动前端 Vite 开发服务器（支持热重载）
pnpm --filter @guandan/web dev
```

### 部署至 Cloudflare
```bash
# 一键编译前端、同步静态资源并发布至 Cloudflare 生产环境
pnpm --filter @guandan/server deploy
```

## 🎴 掼蛋核心规则支持

- **牌型全覆盖**：单张、对子、三张、三带二、顺子（五张）、三连对（木板）、三同连张（钢板）。
- **炸弹体系**：4~8 张炸弹、同花顺（威力仅次于天王炸）、四大天王（大王大王小王小王，最大天王炸）。
- **特殊规则**：
  - 级牌体系（2~A 级数升级）。
  - 逢人配（主牌红桃为万能配牌，可任意组合出顺子、同花顺、炸弹等）。
  - 接风与进贡还贡机制。
